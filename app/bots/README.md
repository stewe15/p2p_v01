# Telegram Боты для P2P торговли звёздами

Этот проект содержит двух Telegram ботов для торговли Telegram звёздами:

- **bot1Payer.py** - Бот для продавцов (показывает сделки, статистику)
- **bot2Buyer.py** - Бот для покупателей (покупка звёзд с кнопкой оплаты)

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Создайте файл `config.env` в папке `app/bots/`:



**Получение токенов:**
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot` и следуйте инструкциям
3. Скопируйте полученные токены в `config.env`

📖 **Подробная инструкция:** См. файл `SETUP.md`

### 3. Запуск Flask API

Убедитесь, что ваш Flask backend запущен на `http://localhost:5000`:

```bash
cd backend
python app.py
```

### 4. Запуск ботов

**Вариант 1: Автоматический запуск**
```bash
python run_bots.py
```

**Вариант 2: Ручной запуск**

Терминал 1 (Бот продавца):
```bash
python bot1Payer.py
```

Терминал 2 (Бот покупателя):
```bash
python bot2Buyer.py
```

## 🔗 QR коды для конкретных сделок

### Генерация QR кодов

Теперь QR коды генерируются для конкретных сделок:

**Для покупателя:**
```bash
curl -X POST http://localhost:5000/generateBuyer \
  -H "Content-Type: application/json" \
  -d '{"dealId": "your_deal_id"}'
```

**Для продавца:**
```bash
curl -X POST http://localhost:5000/generateSeller \
  -H "Content-Type: application/json" \
  -d '{"dealId": "your_deal_id"}'
```

### Как это работает

1. **Создание QR кода:** Отправляете POST запрос с `dealId`
2. **QR код содержит ссылку:** `https://t.me/buyer_stars_kur_bot?deal=deal_id`
3. **Пользователь сканирует QR:** Бот автоматически открывает конкретную сделку
4. **Покупка/просмотр:** Пользователь сразу видит нужную сделку с кнопкой "Купить"

## 🛠️ Разработка

### Добавление новых команд

1. Добавьте обработчик в соответствующий файл бота
2. Используйте декоратор `@dp.message(Command("команда"))`
3. Перезапустите бота

### Обработка callback'ов

Для inline кнопок используйте:

```python
@dp.callback_query()
async def callback_handler(callback: types.CallbackQuery):
    data = callback.data
    # Ваша логика
```

## 🐛 Устранение неполадок

### Бот не отвечает
- Проверьте правильность токена
- Убедитесь, что Flask API запущен
- Проверьте логи в консоли

### Ошибки API
- Убедитесь, что Flask сервер работает на порту 5000
- Проверьте правильность URL в настройках ботов

### Проблемы с зависимостями
```bash
pip install --upgrade aiogram aiohttp requests
```
