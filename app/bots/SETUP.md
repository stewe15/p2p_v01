## 2. Получение токенов ботов

### Создание ботов через @BotFather:

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте `/newbot`
3. Введите имя бота (например: "Stars Seller Bot")
4. Введите username бота (например: "stars_seller_bot")
5. Скопируйте полученный токен
6. Повторите для второго бота

### Пример токена:
```
1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```



## 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 5. Проверка настроек

Запустите ботов для проверки:

```bash
python run_bots.py
```

Если все настроено правильно, боты запустятся без ошибок.

## 🔒 Безопасность

⚠️ **Важно:** 
- Никогда не коммитьте файл `config.env` в git
- Добавьте `config.env` в `.gitignore`
- Используйте разные токены для продакшена

## 🐛 Устранение проблем

### Ошибка "BOT_TOKEN не найден"
- Проверьте, что файл `config.env` существует
- Убедитесь, что токены указаны правильно
- Проверьте, что нет лишних пробелов в токенах

### Ошибка "ModuleNotFoundError: No module named 'dotenv'"
```bash
pip install python-dotenv
```

### Бот не отвечает
- Проверьте правильность токенов
- Убедитесь, что боты запущены через @BotFather
- Проверьте логи в консоли
